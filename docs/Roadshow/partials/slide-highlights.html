六种导航语义，一条统一流程

SceneManager 维护场景栈，提供 PushScene、PopScene、SetupNext、StartGame、ReturnTo、ReturnToMenu 六种操作。每个场景只声明意图，不关心栈结构。

SetupNext替换栈顶，设置页不堆叠。
StartGame保留 Menu+ModeSelect，清除设置链。
PushScene压入覆盖层（暂停、子菜单）。
ReturnToMenu搜索目标层，清除其上所有层。
Menu→Mode→Setup→Map→Game→Over
[Menu] PushScene(ModeSelect) → [Menu, ModeSelect] PushScene(Setup) → [Menu, ModeSelect, Setup] SetupNext(MapSelect) → [Menu, ModeSelect, MapSelect] StartGame(Game) → [Menu, ModeSelect, Game] ← 清除 Setup PushScene(Pause) overlay → [Menu, ModeSelect, Game, Pause] PopScene() → [Menu, ModeSelect, Game] SetupNext(GameOver) → [Menu, ModeSelect, GameOver] ENTER → SetupNext(MapSelect) → [Menu, ModeSelect, MapSelect] ← 再来一局 ESC → ReturnToMenu() → [Menu]

组合优于继承，数据驱动

一个 Tank 类承载所有类型。差异由 TankType 枚举 + TANK_STATS 属性表驱动；控制方式由 IController 策略接口切换。新增坦克类型只需加一行数据。

TankStats 表速度 / 生命 / 护甲 / 冷却 / 最大子弹数。
3 种控制器PlayerController · AIController · NetController。
TankFactory工厂模式，按 TankType + Controller 组装。
护甲公式effectiveDmg = max(1, bulletDmg - armor)。

策略模式：同一坦克，三种控制

IController 是一个极简接口，只有 Update 和 IsAI 两个方法。PlayerController 读键盘，AIController 运行三态状态机，NetController 接收网络输入。Tank 不关心谁在控制它。

PlayerController绑定 5 个按键，直接驱动坦克移动和射击。
AIControllerPATROL → CHASE → ATTACK 三态 FSM。
NetController接收 Host 转发的位掩码，模拟远程输入。
TankFactory工厂模式组装 Tank + Controller。

重叠推力算法，T 型路口零穿墙

13×13 瓦片网格，64px 瓦片。碰撞系统分三路：子弹-地图、坦克-地图、实体-实体。坦克碰墙时按 X/Y 轴独立检测所有重叠墙壁，计算净推力后一次性应用。

BulletMap砖墙破坏、钢墙消失、基地事件。
TankMap按轴分离 + 多墙推力合成。
EntityEntity层过滤 + AABB 碰撞检测。
6 种瓦片EMPTY · BRICK · STEEL · WATER · GRASS · BASE。

BRICK 可破坏
STEEL 不可破坏
WATER 不通行
GRASS 可通行遮挡

Host 端权威，PIMPL 隔离

Host 运行完整游戏逻辑，Client 只发送输入和渲染远程状态。Winsock2 头文件与 raylib 冲突，通过 PIMPL 将所有 socket 类型隐藏在 NetworkManager::Impl 中。

Client → Host60Hz 发送 InputState（位掩码）。
Host → Client20Hz 广播 GameState（全量状态）。
PIMPLNetworkManager::Impl 隐藏 winsock2.h。
