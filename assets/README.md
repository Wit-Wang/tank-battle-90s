# assets/ — 游戏资源

## 目录结构

| 目录 | 内容 | 格式 |
|---|---|---|
| `maps/` | 地图数据，按模式分目录 | TXT |
| `textures/` | 精灵图、瓦片图 | PNG |
| `fonts/` | 字体文件 | TTF |

## 地图目录

```
assets/maps/
├── traditional/       # 传统对战: 2 基地对称地图
├── attack_defend/     # 攻防战: 1 基地攻防地图
├── ffa/               # 各自为战: 无基地竞技场
└── *.txt              # 旧版兼容地图 (自动识别为传统模式)
```

## 地图文件格式

纯文本，每行 13 个数字 (空格分隔)，共 13 行：

```
0 = 空地 (可通行)
1 = 砖墙 (可破坏)
2 = 钢墙 (不可破坏)
3 = 水面 (不可通行)
4 = 草地 (遮挡，可通行)
5 = 基地 (加载后清除为 EMPTY，基地作为独立 Entity)
```

## 添加新地图

在对应模式子目录下创建 `.txt` 文件即可，MapManager 会自动扫描。
